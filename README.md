# 1. Tên dự án ✅

**English-Study**

# 2. Ứng dụng của dự án

Ứng dụng học từ vựng tiếng Anh cá nhân — cho phép thêm từ vựng tự do (không theo lộ trình có sẵn), tổ chức theo từng Bài học, và ôn tập bằng flashcard. Phù hợp cho việc tự học, ôn thi (ví dụ TOEIC), dùng được cả trên máy tính lẫn điện thoại.

# 3. Công nghệ sử dụng

| Hạng mục | Công nghệ |
|---|---|
| Framework | Next.js 16 (App Router, TypeScript) |
| Giao diện | Tailwind CSS |
| Database | PostgreSQL (Neon, serverless) |
| ORM | Prisma |
| Đăng nhập | Auth.js + Google OAuth |
| Tự động điền từ | Free Dictionary API + MyMemory Translation API |
| Hosting | Vercel |

# 4. Hướng dẫn sử dụng

1. **Đăng nhập** bằng tài khoản Google.
2. Vào **Từ vựng** → tạo **Bài học** (ví dụ: Bài 1, Bài 2...) để phân loại từ.
3. **Thêm từ**: gõ từ tiếng Anh, bấm "Tự động điền" để lấy nghĩa/phiên âm/câu ví dụ, chọn Bài, rồi lưu. Hoặc dùng **Nhập hàng loạt** để dán nhiều từ cùng lúc, bổ sung nghĩa sau.
4. Dùng ô **tìm kiếm** hoặc **lọc theo Bài** để xem lại từ đã thêm; có thể sửa, xoá từng từ hoặc chọn nhiều từ để xoá cùng lúc.
5. Vào **Ôn tập**, chọn Bài muốn ôn (hoặc ôn tất cả), lật từng thẻ và tự đánh giá **Nhớ rồi** / **Chưa nhớ**.
6. Trên điện thoại, có thể **"Thêm vào Màn hình chính"** để cài app như ứng dụng thật.
